# Assignment 1 - TypeScript

## Overview
This repository contains my solutions for Assignment 1 of the Next Level Web Development course. It covers the basics of TypeScript, including:

- Basic types, optional parameters, and default parameters
- Type narrowing with `typeof` and other type guards
- Tuples and the `readonly` keyword
- Generic functions and rest parameters
- Interfaces and object filtering
- Object-Oriented Programming (classes, inheritance, and access modifiers)
- Async functions and Promises

All coding problems are solved in a single file: [`solutions.ts`](./solutions.ts).
